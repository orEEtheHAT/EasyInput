# Getting Started

**Compatibility:** EasyInput 0.2.0+. No prerequisite sample imports.

After importing, choose Tools > EasyInput > Create Getting Started Scene, then Play. The panel opens with sensitivity, per-binding rebinding, reset and in-memory Capture/Restore. Close with Escape/East; reopen with Tab/Start. Gameplay Interact defaults to E/Gamepad West. Mouse or right stick rotates the preview cube. Use a gamepad's D-pad and South to navigate/select panel rows.

This scene is an input preview, not an FPS controller. Import the optional EasyMovement sample for the ECM2-based player. Full installation and API examples are in the package README.
