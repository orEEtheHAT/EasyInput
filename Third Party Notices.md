# Asset provenance

The included button glyph PNGs are original geometric drawings created for EasyInput. They contain simple keycaps, rings, direction marks and bars; no vendor logos or third-party icon artwork are included. Text such as Xbox/PlayStation/Switch identifies device compatibility only. Glyph sets can be replaced with licensed project artwork through InputGlyphSet assets.

Unity Input System is an external UPM dependency distributed under its own Unity package license. The package does not redistribute ECM2 or the optional EasyMovement, EasyFeedbacks, EasyBuilding, EasyInteraction, EasyResources, EasyCombat, EasyLocalization or EasyUI dependencies.
